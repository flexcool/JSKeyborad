# JSKeyborad

iOS 输入法工具，支持文本模板管理和快速插入。

## 功能特性

### 文本模板管理
- 创建和管理常用文本模板（地址、话术、签名、邮件模板等）
- 文件夹分类整理，自定义图标和颜色
- 使用统计，了解你最常用的模板
- 搜索功能，秒级定位目标模板

### 自定义键盘
- 在微信、短信、邮件等任意 App 中快速插入模板
- 文件夹标签快速筛选
- 搜索框即时查找
- 插入成功即时反馈

### 变量插值（Pro）
- 使用 `{变量名}` 语法插入动态内容
- 系统变量自动填充：`{today}` 日期、`{now}` 时间
- 自定义变量：支持默认值
- 适合需要动态内容的模板场景
- 支持自定义 JS 脚本，包含或不包含 `(args)` 运行后输出

### 智能整理
- 内置常用、工作、个人三个文件夹
- Pro 用户可创建无限自定义文件夹
- 模板置顶，常用内容优先显示
- 支持手动排序、使用频次排序、最近使用排序

### 桌面小组件
- 小号小组件：显示 3 个常用模板
- 中号小组件：显示 6 个常用模板
- 点击即可复制模板内容到剪贴板

### 数据管理
- JSON 格式导出全部数据，方便备份
- 从 JSON 文件导入，轻松迁移
- 批量选择、移动、删除模板

### 隐私安全
- 键盘不需要「允许完全访问」权限
- 所有数据仅存储在你的设备本地
- 不收集、不上传任何用户输入数据
- 无第三方分析或广告 SDK

## 如何启用键盘

1. 打开系统「设置」，依次进入「通用」「键盘」「键盘」
2. 点击「添加新键盘」
3. 选择「JSKeyborad」
4. 在任意输入框长按地球键切换到 JSKeyborad 键盘

## 系统要求

- iOS 16.0 或更高版本
- iPhone 或 iPad

## 开发环境

- Xcode 15.0+
- Swift 5.9+
- iOS 16.0+


## 构建

### 本地构建

1. 克隆仓库
2. 打开 `JSKeyborad.xcodeproj`
3. 选择模拟器或真机
4. 按 `Cmd + R` 运行

### GitHub Actions

推送到 `main` 或 `develop` 分支会自动触发构建。
